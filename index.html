ABOUT

What is WatchTrace?

WatchTrace is a desktop application for Windows that helps you keep track of movies and TV series. It provides a personal space to manage what you've watched and what you plan to watch.

The project was created as an alternative to services that require an account to track movies and TV series. WatchTrace keeps personal data stored locally on the user's computer, without requiring registration or login.

Developed as an engineering thesis project.

Movie & Series data provided by TMDb

This product uses the TMDb API but is not endorsed or certified by TMDb.
