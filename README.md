## 📖 Description

**WatchTrace Website** is the official landing page for **WatchTrace**, a Windows desktop application for organizing movie and TV series collections, managing watchlists, and tracking watched content.

The website presents the application's planned features, its development status, and general information about the project.

WatchTrace is being developed as part of an **engineering thesis project**.

---

<br>

## 🚧 Project Status

The **WatchTrace desktop application** is currently under development.

The website will be updated as the project progresses.
